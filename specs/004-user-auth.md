# 004：用户注册与登录

> 状态：草案
> 关联事项：无

## 目标

用户可以注册账号、登录系统、管理个人信息，为后续预测竞猜、评论讨论和排行榜功能提供统一的身份标识。

## 用户故事

作为一名球迷，我希望注册一个个人账号并登录系统，以便在平台中拥有唯一身份，参与预测竞猜、发表评论、查看个人统计以及出现在排行榜中。

## 范围

- 用户通过用户名和密码注册账号
- 用户通过用户名和密码登录，获得会话令牌
- 登录状态在浏览器端持久化，关闭页面后重新打开仍保持登录
- 登录后可查看个人主页，展示基本信息和活动统计
- 用户可在个人主页修改隐私设置
- 令牌过期或失效时，系统提示用户重新登录
- 未登录用户可浏览赛事数据，但预测、评论、发帖等操作需先登录
- 导航栏根据登录状态展示不同内容（未登录显示登录按钮，已登录显示头像和用户名）

## 非目标

- 第三方 OAuth 登录（微信、GitHub 等）不属于本期范围
- 邮箱注册、手机号注册、邮箱验证、密码找回不属于本期范围
- 头像上传功能不属于本期范围（使用默认字母头像）
- 用户之间的关注、私信等社交功能不属于本期范围
- 管理后台的用户管理功能不属于本期范围
- 用户预测记录和评论历史的详细展示属于对应 Spec 交付范围，个人主页仅展示统计摘要

## 业务规则

- **BR-01**：用户名长度 3-16 字符，仅允许字母、数字和下划线，注册时去首尾空格后校验唯一性
- **BR-02**：密码长度不少于 6 字符，注册时以明文传输、后端哈希存储，登录时比对哈希值
- **BR-03**：登录成功后返回会话令牌，令牌有过期时间；令牌过期后受保护接口返回未认证状态
- **BR-04**：同一用户名注册失败（已被占用或格式不合法）时，返回可读的错误提示，不透露该用户名是否真实存在
- **BR-05**：登录失败时统一返回用户名或密码错误，不单独提示用户名不存在
- **BR-06**：用户可设置两项隐私开关：是否允许出现在排行榜、是否允许他人查看自己的预测记录；默认均为允许
- **BR-07**：游客仅可浏览赛事数据、球队球员信息和讨论区只读内容；提交预测、发表评论、发布帖子必须登录
- **BR-08**：令牌失效时，前端清除本地存储的令牌和用户信息，展示重新登录提示，不出现空白页面

## Contract 影响

- 结论：新增
- 理由：用户系统需要注册和登录端点，与现有赛事数据查询端点无关
- OpenAPI operation：
  - `POST /api/auth/register` — 注册，请求体包含 username 和 password，成功返回用户信息和令牌
  - `POST /api/auth/login` — 登录，请求体包含 username 和 password，成功返回用户信息和令牌
  - `GET /api/auth/me` — 获取当前登录用户信息，需要 Authorization 头，用于验证令牌有效性和获取最新用户数据
  - `PATCH /api/auth/me` — 更新当前用户隐私设置，需要 Authorization 头
- 安全说明：所有预测、评论、发帖等受保护接口需要 Authentication 头携带令牌，具体鉴权行为在对应 Spec 的 Contract 中定义
- 迁移 / 废弃安排：不适用，全部为新增端点

## 验收标准

- **AC-01**：给定尚未注册且格式合法的用户名和密码，当用户提交注册请求时，则成功创建账号并返回令牌
- **AC-02**：给定已被占用的用户名，当用户提交注册请求时，则返回明确的错误提示，不触发重复注册
- **AC-03**：给定少于 3 字符或多于 16 字符或包含非法字符的用户名，当用户提交注册请求时，则返回格式校验失败提示
- **AC-04**：给定少于 6 字符的密码，当用户提交注册请求时，则返回密码长度不足的提示
- **AC-05**：给定已注册的合法用户名和正确密码，当用户提交登录请求时，则成功返回令牌
- **AC-06**：给定已注册但密码错误的凭证，当用户提交登录请求时，则返回用户名或密码错误的统一提示
- **AC-07**：给定有效的令牌，当用户请求获取个人信息时，则返回用户基本信息
- **AC-08**：给定无效或已过期的令牌，当用户请求获取个人信息时，则返回未认证状态
- **AC-09**：给定未登录用户访问注册页或登录页，当页面加载完成后，则展示可用的注册和登录表单
- **AC-10**：给定登录页已展示，当用户填写合法凭证并提交时，则登录成功后页面跳转至首页，导航栏展示用户名
- **AC-11**：给定用户已登录，当令牌失效后用户访问受保护页面时，则清除本地存储并展示重新登录提示
- **AC-12**：给定用户已登录，当用户访问个人主页时，则展示用户名、注册时间和隐私设置开关
- **AC-13**：给定游客访问赛事数据页面，当用户尝试提交预测或评论时，则操作入口置灰并引导用户登录
- **AC-14**：给定用户使用键盘操作注册和登录表单，当遍历全部输入框和按钮时，则每个可操作元素具备可见焦点，输入框带有关联标签

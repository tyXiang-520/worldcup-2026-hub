# 001：世界杯赛事数据展示

> 状态：草案
> 关联事项：无

## 目标

用户可以浏览 2026 美加墨世界杯全部赛事的赛程，按阶段筛选，查看每场比赛的详细数据，并可从比赛详情页自由跳转至球队和球员页面。

## 用户故事

作为一名球迷，我希望查看世界杯全部赛事的赛程和每场比赛的详细数据，以便了解赛事全貌和自己关注的球队与球员表现。

## 范围

- 按时间顺序展示 2026 美加墨世界杯全部赛事（48 支球队，共 104 场）
- 按比赛阶段筛选赛程（全部 / 小组赛第N轮 / 淘汰赛各阶段）
- 每场比赛卡片展示：开球时间、主客队（队徽与名称）、最终比分、一句话简述
- 不同类型赛场事件使用差异化视觉标识以区分进球、红黄牌、换人等事件
- 比赛详情页提供多组信息分区用于切换查看不同维度数据（含赛况数据、阵容名单、球员评分、讨论区占位）
- 赛况分区展示双方数据对比和赛场事件时间线
- 阵容分区展示双方首发名单与替补名单
- 球员评分分区展示双方球员评分，得分最高球员突出标识
- 点击队徽或球队名称跳转至球队详情页（本期仅实现路由跳转与基本占位）
- 点击球员姓名跳转至球员详情页（本期仅实现路由跳转与基本占位）
- 赛事卡片按日期分组展示，每组附带日期标题
- 阶段筛选器默认展示全部赛事

## 非目标

- 晋级图、射手榜、助攻榜、积分榜属于后续独立 Spec 交付范围
- 讨论区的评论发布、回复、表情互动等交互功能属于后续独立 Spec 交付范围
- 预测竞猜功能属于后续独立 Spec 交付范围
- 用户登录注册、认证鉴权属于后续独立 Spec 交付范围
- 管理后台的数据录入与管理功能属于后续独立 Spec 交付范围
- 本 Spec 不实现球队、球员详情页的完整数据展示逻辑，仅提供基础路由跳转入口，完整页面能力由后续 Spec 独立交付
- 本 Spec 不实现实时比分推送，所有赛事数据均为 2026 世界杯历史固定赛果的静态展示

## 业务规则

- **BR-01**：赛程按比赛日期升序排列，同一日期的比赛按开球时间升序排列
- **BR-02**：阶段筛选器默认展示"全部"，用户选择特定阶段后仅展示匹配赛事
- **BR-03**：所有赛事均为 2026 世界杯历史固定赛果，页面统一展示最终比分，不存在实时动态赛事状态
- **BR-04**：比赛事件时间线按发生分钟数升序排列，不同事件类型（进球、黄牌、红牌、换人、VAR 介入）使用差异化视觉标识以便用户区分
- **BR-05**：首发名单中的球员信息包含球衣号码和姓名，替补名单独立列出
- **BR-06**：球员评分范围 1-10 分，单场得分最高的球员以视觉方式突出标识
- **BR-07**：所有球队和球员的点击跳转为独立路由，支持浏览器前进与后退操作
- **BR-08**：赛事数据为静态种子数据，页面首次加载时展示加载状态；数据为空时展示空状态说明；请求失败时展示错误提示，不含内部技术细节
- **BR-09**：未登录游客仅可浏览全部赛事静态数据，预测提交和评论发帖等需要用户身份的功能对游客不可用（相关功能的权限校验在对应 Spec 中交付）

## Contract 影响

- 结论：新增
- 理由：赛事数据展示需要新增全新的 API 端点，与现有课程 API（`/api/health`、`/api/courses`）无关
- OpenAPI operation：
  - `GET /api/matches` — 赛程列表，支持可选查询参数 `?stage=` 按阶段筛选
  - `GET /api/matches/:id` — 单场比赛详情，响应含比赛基本信息、赛场事件列表、双方首发与替补名单、球员评分列表
  - `GET /api/teams` — 球队列表
  - `GET /api/teams/:id` — 球队详情（本期响应仅含基本信息，完整数据由后续 Spec 交付）
  - `GET /api/players/:id` — 球员详情（本期响应仅含基本信息，完整数据由后续 Spec 交付）
- 迁移 / 废弃安排：不适用，全部为新增端点

## 验收标准

- **AC-01**：给定赛事接口正常返回完整数据，当用户访问赛程页面，则全部赛事按日期分组展示，每组附带日期标题
- **AC-02**：给定完整的赛事数据，当用户在阶段筛选器中选择某个特定阶段（如"小组赛第1轮"），则页面仅展示该阶段对应的赛事
- **AC-03**：给定一场已完成的比赛，当用户查看其赛事卡片时，则卡片展示最终比分（主队在前、客队在后）和一句话简述
- **AC-04**：给定赛事接口响应延迟，当用户访问赛程页面等待数据加载时，则页面展示可识别的加载状态
- **AC-05**：给定赛事接口请求失败，当页面完成请求后，则展示错误提示信息，且不包含内部技术细节（如堆栈、SQL 语句）
- **AC-06**：给定阶段筛选后无匹配赛事，当页面完成筛选渲染后，则展示明确的空结果说明
- **AC-07**：给定赛事数据已加载完成，当用户点击某场比赛卡片时，则进入对应比赛详情页，默认展示赛况信息分区
- **AC-08**：给定比赛详情页已加载，当用户查看赛况分区时，则可见双方数据对比和赛场事件时间线，不同类型事件以差异化视觉标识区分
- **AC-09**：给定比赛详情页已加载，当用户切换到阵容分区时，则可见双方首发名单与替补名单，每名首发球员包含球衣号码和姓名
- **AC-10**：给定比赛详情页已加载，当用户切换到球员评分分区时，则可见双方球员评分列表，得分最高的球员以视觉方式突出标识
- **AC-11**：给定比赛详情页已加载，当用户切换到讨论分区时，则展示占位内容，提示该功能尚未开放
- **AC-12**：给定赛事详情页中展示了球队信息，当用户点击队徽或球队名称时，则浏览器导航至对应球队详情页，且支持浏览器后退返回
- **AC-13**：给定赛事详情页中展示了球员信息，当用户点击球员姓名时，则浏览器导航至对应球员详情页，且支持浏览器后退返回
- **AC-14**：给定球队和球员详情接口仅返回基本信息，当用户访问球队或球员详情页时，则展示基本占位内容（名称与标识），并提示完整数据即将上线
- **AC-15**：给定用户仅使用键盘操作页面，当遍历阶段筛选器、赛事卡片和跳转链接等全部交互控件时，则每个可操作元素具备清晰可见的焦点状态，页面关键区域带有辅助技术可识别的语义标签

# 008：管理后台

> 状态：草案  
> 关联事项：依赖全部已有 Spec  

## 目标

管理员可以通过后台页面管理比赛、录入结果，确保平台数据可维护。

## 范围

- 管理员登录（通过特定用户名区分）
- 比赛管理：查看赛程、录入比分和事件
- 球员管理：查看球员列表
- 仅管理员账号可访问 `/admin`

## 非目标

- 富文本编辑、批量导入属于后续
- 用户管理、权限角色系统不属于本期

## 业务规则

- BR-01：只有 username 为 admin 的用户可访问管理后台
- BR-02：普通用户访问 /admin 返回 403
- BR-03：录入比分后自动更新比赛状态

## Contract 影响

- 结论：新增
- OpenAPI：`PATCH /api/admin/matches/:id`

## 验收标准

- AC-01：管理员登录后可访问管理后台
- AC-02：普通用户访问管理后台被拒绝
- AC-03：管理员可更新比赛比分和摘要
